== Description ==
Rara Travel & Tour is a WordPress theme scaffold for a bus transportation landing page. It includes responsive sections for hero, services, fleet, routes, testimonials, booking, blog templates, sidebars, and WooCommerce placeholders.

== Features ==
* Responsive landing page layout
* WordPress header and footer templates
* Page, single, archive, search, comments, and 404 templates
* Primary and WooCommerce sidebars
* WooCommerce wrapper template
* Asset folders for CSS, JS, images, and vendors
* Theme thumbnail helper file and generated image.png

== Installation ==
1. Copy the theme folder into wp-content/themes/.
2. Activate "Rara Travel & Tour" from Appearance > Themes.
3. Configure menus, widgets, and WooCommerce if needed.
